# Atlas Player

Atlas Player es una aplicación IPTV gratuita con playlist integrada, orientada a usuarios latinos de Android TV.

## Características

- Lista de canales disponibles.
- Gestión de canales favoritos.
- Barra de búsqueda.
- Desplazamiento rápido entre canales con los números del control remoto.
- Lista de opciones alternativas para el canal actual.
- Experiencia similar a las TV por cable.

## Navegación

La interfaz separa la navegación de canales de la selección de fuentes:

- **Drawer izquierdo:** muestra una entrada por canal y permite recorrer la playlist, buscar contenido y acceder a tus canales favoritos.
- **Drawer derecho:** muestra las fuentes alternativas disponibles para el canal actual.
- **Área de reproducción:** presenta el contenido en orientación horizontal, optimizada para la experiencia en televisión.

## Requisitos generales

- Android TV.
- Conexión a nternet.

## Notas
- Esta aplicación fué creada en su totalidad con inteligencia artificial, por lo que es probable que se encuentrem bugs o errores durante su uso.
- La playlist integrada contiene una compilación de links funcionales de diferentes canales de televisión encontrados en foros públicos de internet, es por esto que no se garantiza la correcta emisión de los canales ni que estos sigan funcionando en un futuro.
